【A 版 · 200 字以内】
----------------------------------------------------------------
见报电子报纸下载器是 Windows 桌面软件，按日期获取报纸电子版的各版 PDF，并按版序
合并为整份报纸。内置人民日报、人民日报海外版、经济日报、中国能源报、法治日报、大
众日报等八个来源，支持日期步进、日历选择、最新一期探测、版面检索、多线程下载与偏
好保存及命令行批量下载。界面以 Win32 与 GDI+ 全自绘，单文件免安装；自研 PDF 合并器
按对象级重编号合并各版，合并前校验引用完整性，避免缺页缺图。


【B 版 · 约 1100 字】
----------------------------------------------------------------
一、研发背景
报纸电子版通常按版面分散发布为单个 PDF 文件，一期报纸少则四版、多则二十余版。
读者查阅时需要逐版下载、逐版打开，既不便保存也不便阅读。本软件面向这一实际需求，
把同一期报纸的各版 PDF 按版序合并为一份完整文件，使文件结构与纸质报纸一致，可一
次翻阅、一次打印、一次归档。

二、核心架构
软件采用三层结构。界面层为 Win32 无边框窗口，标题栏、导航栏、版面卡片、任务面
板均由 GDI+ 矢量绘制，不依赖第三方界面库；任务层由工作线程执行网络与合并操作，
通过消息通知界面刷新进度，并用请求序号标记每次任务，快速切换日期或来源时自动丢
弃过期结果，避免界面串图；数据层包含报纸来源解析、HTTP 传输与 PDF 合并三个模
块，界面与控制台共用同一套任务代码。

三、功能模块
1. 来源管理：内置人民日报、人民日报海外版、经济日报、中国能源报、法治日报、大众
   日报、农村大众、山东法制报八个数字报来源，可在左栏一键切换，切换后按同一日期
   重新载入版面；来源表按站点族参数化，同类站点增加一行即可接入。
2. 日期导航：日期步进器、月历弹窗、最新一期自动探测，无报纸的日期给出提示并支持
   跳转到最近可下载日期。
3. 版面列表：卡片网格与列表两种视图，显示版号、版名、头条标题与矢量绘制的版面缩
   略图；解析不到标题时以占位图形呈现，不虚构内容。
4. 版面检索：按版名、版号、头条标题即时过滤，支持全选与逐版点选。
5. 任务面板：显示已选版面、输出文件名预览、下载进度、已下载体积与保存目录，可设
   置是否合并、是否下载后打开目录。
6. 记录与设置：下载记录、保存目录、上次选择的来源等写入用户配置目录，下次启动自
   动恢复。
7. 命令行模式：同一可执行文件支持 --source、--date、--latest、--pages、--info 等
   参数，便于批量下载与脚本调用。

四、技术实现
PDF 合并为本软件自研，不依赖任何第三方 PDF 库：线性扫描对象并识别流数据边界，
支持直接长度与间接长度两种写法；为各源文件分配对象号区间做整体重编号，只改写字典
区中的间接引用，流数据整段照抄；重建页面树与交叉引用表并写入文档标题。合并前逐个
校验被引用对象是否齐全，缺失即中止并报出版号与对象号，宁可报错也不产出残损文件。
界面按 Per-Monitor V2 做高 DPI 缩放，整帧渲染到离屏位图后一次呈现以避免闪烁。网
络层基于 WinHTTP，按状态码分类提示错误。

五、应用场景
适用于教学资料整理、报刊内容研究与比对、个人阅读与长期归档，也可作为报纸数字化素
材的批量采集工具。
