三、主要功能
----------------------------------------------------------------
  1. 内置人民日报、经济日报、法治日报、大众日报四家数字报来源，可一键切换。
  2. 按日期浏览与下载：日期步进、日历选择、自动探测最新一期。
  3. 版面列表：卡片网格与列表两种视图，展示版名、头条标题与仿真缩略图。
  4. 版面检索：按版名、版号、头条标题即时过滤；支持全选与逐版点选。
  5. 多线程下载各版官方 PDF，并按版序合并为单一 PDF；可关闭合并保留分版。
  6. 任务面板显示已选版面、输出文件名、进度、已下载体积与保存位置。
  7. 下载记录与偏好设置持久化（保存目录、是否合并、是否下载后打开目录）。
  8. 命令行模式，支持按参数批量下载与只列出当日版面。

四、技术特点
----------------------------------------------------------------
  1. 采用 C++17 与 Win32 API 开发，界面完全自绘（GDI+ 矢量绘制），不使用
     第三方界面库，程序为单个可执行文件，无运行时依赖。
  2. 自研 PDF 合并器，不依赖任何 PDF 库：线性扫描对象、整体重编号、改写
     间接引用、重建页面树与交叉引用表；支持直接与间接 /Length、二进制流
     跳过、字面字符串与十六进制串识别。
  3. 合并前做引用完整性校验，对象缺失即中止并报出版号与对象号，避免产出
     缺图缺页的残损文件。
  4. 网络层基于 WinHTTP，支持超时重试、状态码分类提示与最新可下载日期探测。
  5. 界面按 Per-Monitor V2 做 DPI 缩放；后台线程执行网络与合并任务，并用
     请求序号丢弃过期结果，避免快速切换日期或来源时出现串图。
