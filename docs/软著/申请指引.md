# 计算机软件著作权登记 · 报送指引

> 适用：见报电子报纸下载器 V1.1.1　著作权人：李强（个人）
> 本指引按中国版权保护中心现行在线登记流程整理，办理时以系统页面提示为准。

## 一、报送前的三个基本判断

| 项目 | 结论 |
| --- | --- |
| 是否收费 | **不收费**。自 2017 年 4 月 1 日起停止征收计算机软件著作权登记费（财税〔2017〕20 号），自行提交不收任何官费；委托代理或走加急才产生服务费 |
| 办理时限 | 受理后 **60 日内**审查完成；材料有问题会通知补正，须在 **30 日内**补正，逾期视为撤回 |
| 是否需要寄纸质件 | 不需要。全程在线，电子证书为带签名的 PDF，可在用户中心下载 |

## 二、办理流程

1. **注册账号** — 中国版权保护中心官网（`www.ccopyright.com.cn`）进入「著作权登记系统」（`register.ccopyright.com.cn`）。
2. **实名认证** — 个人需完成实名认证后才能提交软件登记业务，按系统指引上传身份证信息并完成校验。
3. **填报** — 选择「软件著作权登记」，按 `登记信息表.txt` 逐字段填写；功能描述从 `功能描述.txt` 复制。
4. **上传材料** — 四类：源程序鉴别材料、文档鉴别材料、身份证明、申请确认签章页。
5. **签章页** — 系统生成「申请确认签章页」后打印，**本人手写签字**，扫描或拍照上传。未签字的签章页一律不予受理，这是最常见的退回原因。
6. **提交 → 受理 → 审查** — 受理后进入审查；期间留意系统通知与短信，补正通知有时限。
7. **取证** — 登记完成后在用户中心下载电子证书，并可在官网查阅登记公告。

## 五、关于「首次发表日期」

本软件已于 **2026-11-05** 在 GitHub 公开发布 v1.1.1（MIT 许可，含源码与可执行文件），
因此首次发表日期客观上已经发生，应如实填写 **2026-11-05**。

- **建议按已发表填报。** 公开发布记录（仓库创建时间、首个 commit、Release 发布时间）本身就是佐证，如实填写没有风险；登记审查只核对材料一致性，不要求软件未曾公开。
- **若坚持按「未发表」填报**，必须先下架仓库并使 Release 不可访问，再提交申请——否则属于填报不实，反而可能被要求补正。考虑到已经公开、且开源有利于项目传播，不建议这样做。
- 保留佐证：仓库页面截图、Release 页面截图各存一份，与申请材料一并归档备查。

## 六、常见退回原因（逐条自查）

- [ ] 源程序页数不足 60 页，或每页行数明显少于 50 行
- [ ] 源程序页眉没有软件全称或版本号，或与申请表填写不一致
- [ ] 说明书过于简略、没有目录，或缺少界面截图与操作步骤
- [ ] 源程序与说明书中的软件名称、版本号互相矛盾
- [ ] 签章页未签字，或上传了错误的文件（如误传成申请表首页）
- [ ] 软件名称含广告语、他人商标，或与已登记软件重名
- [ ] 申请表中功能描述与说明书正文明显不符

## 七、拿到证书之后

- 电子证书保存在用户中心，为带数字签名的 PDF，可按官网指引验签；如需纸质证书可另行申请。
- MIT 许可与软著**并不冲突**：许可他人使用、修改代码，不影响著作权归属，也不影响已登记的权属。
- 后续版本升级（如 V1.2.0）如需登记，按「新版本登记」另行提交，版本号递增，材料重新按前后各 30 页准备。
- 若日后转让权利或许可他人独占使用，应及时办理登记事项变更或备案。
