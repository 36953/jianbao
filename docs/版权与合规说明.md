# 版权与合规说明

> 核查时间：2026-11-05　适用版本：见报 V1.2.0
> 本文记录八家报纸来源的授权状态、robots 协议、访问控制与法律依据，供使用者与开发者对照。

## 一、结论先说

| 用途 | 是否可行 | 依据 |
| --- | --- | --- |
| 个人下载当期或往期报纸，自己阅读、学习、研究、教学备课 | **可行** | 《著作权法》第 24 条第 1 款第 1 项「为个人学习、研究或者欣赏，使用他人已经发表的作品」属合理使用，不需许可、不付报酬 |
| 把下载的 PDF 转发到群里、上传网盘、发布到公众号或网站 | **不可** | 四家站点均明确「未经许可不得转载」，超出合理使用范围，属侵犯复制权与信息网络传播权 |
| 用于商业用途（印刷、售卖、内容加工、训练语料销售） | **不可** | 同上，且可能构成不正当竞争 |
| 去除水印、删除版权页或改写版面上的权利信息 | **不可** | 《著作权法》第 53 条禁止删除或改变权利管理信息 |
| 使用本软件本身 | **可行** | 软件是中立工具，不存储、不托管、不分发任何报纸内容；下载行为发生在使用者本机 |

一句话：**软件可以公开，报纸内容不能公开。** 工具开源不等于内容授权。

### 几个容易被忽略的点

1. **人民网的声明明确把「版面设计」列入保护范围。** 报纸版面 PDF 不是「一篇篇文章」的集合，它本身就是版式作品，因此「只下版面、不摘文章」并不构成规避。
2. **大众网的 robots.txt 只禁止两个目录**：`/dzrbnew/` 与 `/shexun/`。本工具访问的 `/dzrb/content/…`、`/dzrb/PDF/…` 不在禁止之列——这说明站点并不排斥自动化访问这些公开版面，但也仅止于「不禁止」，不等于「授权转载」。
3. **人民日报另有付费的「图文数据库」**（`data.people.com.cn`）。本工具只访问免费的电子版版面页，不触碰该付费库，也不做全文检索式的批量抓取，避免形成对付费产品的实质性替代。
4. **四家都免费、免登录、无付费墙、无验证码。** 本工具不绕过任何访问控制或技术措施——这是工具中立性最重要的一条边界。

## 三、法律依据

- 《中华人民共和国著作权法》（2020 年修正）
  - 第 10 条：著作权包括复制权、信息网络传播权等。
  - 第 24 条第 1 款第 1 项：**为个人学习、研究或者欣赏，使用他人已经发表的作品**，可以不经著作权人许可，不向其支付报酬，但应当指明作者姓名或名称、作品名称，并且不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益。
  - 第 53 条：禁止未经许可删除或者改变作品的权利管理信息。
- 合理使用是**法定限制**，不因站点单方声明「未经许可不得复制」而被排除；但合理使用仅限于「个人学习、研究、欣赏」，**一旦对外传播即超出边界**。

## 四、本软件已采取的合规措施

| 措施 | 说明 |
| --- | --- |
| 不托管、不分发内容 | 程序不含任何报纸内容，下载结果只写在使用者自己选择的本地目录 |
| 不绕过访问控制 | 只接入免费、免登录、无验证码的公开版面；对返回 403、JS 挑战或需登录的站点一律不接入（光明日报、环球时报、北京日报等已因此排除） |
| 不改动内容 | 合并只做对象级搬运，不重采样、不去水印、不裁剪版权页 |
| 不提供批量历史抓取 | 一次只处理一个日期，需使用者逐日操作；不提供「整月/整年」导出 |
| 控制请求压力 | 并发默认 4 线程，失败退避重试，不使用多 IP 或高频轮询 |
| 遵守 robots | 大众网 robots 禁止的两个目录（`/dzrbnew/`、`/shexun/`）本工具不访问 |
| 显著提示使用边界 | README 顶部、使用说明首页、软件关于页均声明「仅供个人学习、研究、教学使用，不得转载或商用」 |
| 开源但不等于授权内容 | 代码以 MIT 许可开放，许可范围不含报纸内容；LICENSE 中已明确声明 |

## 五、如果收到权利人通知

1. 立即停止分发对应来源：在 `src/sources.cpp` 的来源表中删除该条目，重新构建并发版，使新版本不再支持该来源。
2. 保留沟通记录，说明工具不存储、不分发内容，且不绕过访问控制。
3. 如权利人要求，可暂时下架仓库与 Release（`gh release delete` + 仓库转私有），处理后再恢复。
4. 不对已下载到本机的报纸文件做任何再传播。

## 六、给使用者的提醒

- 下载后请**自己看**，不要转发、不要上传、不要二次发布。
- 引用报纸内容时，注明「来源：《人民日报》2026 年 11 月 5 日第 05 版」。
- 教学使用时，优先在课堂内展示；如需印发给学生，属于复制发行，应取得报社许可或使用报社提供的授权渠道。
- 需要长期存档或商业使用，请直接联系各报社（人民网、中国经济网、法治日报社、大众报业集团）取得授权。
